نیاز مردمی - آپلود روی GitHub Pages
1. در GitHub یک repository بساز (Public).
2. همه‌ی فایل‌های این پوشه را آپلود کن (Add file > Upload files).
3. Settings > Pages > Source: Deploy from a branch > main / root > Save.
4. بعد از چند دقیقه لینک https://USERNAME.github.io/REPO/ آماده است.
5. آن لینک را در pwabuilder.com بده و APK بگیر.
